NPCVO v0.1.4

- Fixed vanilla QuestOffer detection when the visible DaggerfallMessageBox owns/links back to the QuestOffer via PreviousWindow rather than remaining discoverable through the private UI stack.
- Quest-giver names now prefer QuestMachine.LastNPCClicked.DisplayName because TalkManager.SetTargetNPC() has not run yet for direct quest offers.
- Quest portraits now reuse DFU's own GetPortraitIndexFromStaticNPCBillboard resolver against LastNPCClicked, then copy the resulting TalkWindow texture.
- Added npcvo_quest_debug console command to report TopWindow, PreviousWindow chain, detected QuestOwner, display window, extracted text length, and LastNPCClicked.
- Normal TalkWindow capture/voice/reveal behavior is unchanged from v0.1.3.2.
